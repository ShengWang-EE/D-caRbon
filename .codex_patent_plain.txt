说 明 书 摘 要
本发明公开了一种考虑微气候反馈的建筑-电网需求响应碳减排潜力评估方法，属于城市综合能源系统灵活性评估与低碳调度领域。该方法首先获取建筑几何信息、建筑用途、舒适温度区间、气象观测数据以及电力系统机组排放因子，并将城市区域划分为若干空间网格；其次，基于建筑热平衡关系建立单建筑温控负荷等效储能模型，求取基线功率、等效充放电功率及等效储能容量；然后，结合天气站加权温度、建筑密度诱导的城市热岛温升以及空调排热反馈，计算各网格局地温度，并依据局地温度修正空调性能系数，从而更新建筑群需求响应能力；进一步，将聚合后的建筑柔性嵌入电力系统机组组合或经济调度模型，比较接入需求响应前后的发电出力差异，得到建筑群需求响应的碳减排潜力及空间分布结果。本发明能够同时反映建筑热惯性、城市空间异质性和电力系统边际排放差异，适用于能源输入型城市的需求响应规划、建筑群灵活性评估以及建筑-电网协同低碳运行分析。

权 利 要 求 书
1、一种考虑微气候反馈的建筑-电网需求响应碳减排潜力评估方法，其特征在于，包括如下步骤：
S1、获取待评估城市区域的建筑几何信息、建筑用途信息、温控负荷舒适温度区间、气象观测数据以及电力系统发电机组排放因子，并将所述城市区域划分为若干空间网格；
S2、针对每一建筑建立温控负荷热平衡模型，将建筑制冷负荷表征为等效储能，求取基线功率、最大等效充电功率、最大等效放电功率及等效储能容量；
S3、基于所述空间网格，计算天气站加权环境温度、城市热岛温升和空调排热诱导温升，得到各网格局地温度，并依据所述局地温度修正空调性能系数；
S4、对修正后的单建筑等效储能参数进行聚合，得到城市建筑群需求响应包络；
S5、将所述需求响应包络嵌入电力系统机组组合模型或经济调度模型，比较接入需求响应前后的发电出力差异，得到建筑群需求响应的碳减排潜力。
2、根据权利要求1所述的一种考虑微气候反馈的建筑-电网需求响应碳减排潜力评估方法，其特征在于：
所述步骤S1中的建筑几何信息至少包括建筑位置、轮廓面积、高度或体积中的一种或多种；
所述气象观测数据至少包括气温、太阳辐射、湿度和风速中的一种或多种；
所述空间网格采用规则网格或街区单元离散方式，网格边长为250m、500m或根据研究区域尺度自适应设定的其它长度。
3、根据权利要求1所述的一种考虑微气候反馈的建筑-电网需求响应碳减排潜力评估方法，其特征在于：
所述步骤S2中，单建筑的室内热平衡由下式表示：
C_a·ρ_a·V_b·dT_b^r/dt = (T_a - T_b^r)·K_b·A_b^s + C_a·ρ_a·V_b·(T_a - T_b^r)·N_b^ex + ε_b·A_b + I_b^solar·A_b^sol - Q_b^cool
其中，C_a为空气比热容，ρ_a为空气密度，V_b为建筑体积，T_a为环境温度，T_b^r为室内温度，K_b为围护结构传热系数，A_b^s为建筑外表面积，N_b^ex为空气交换率，ε_b·A_b为内部得热项，I_b^solar·A_b^sol为太阳辐射得热项，Q_b^cool为制冷功率；
在室内温度位于最舒适温度时得到基线功率；在室内温度分别位于舒适区间下限和上限时，得到最大等效充电功率与最大等效放电功率；
所述等效储能容量由建筑热惯性和舒适温度区间共同决定。
4、根据权利要求3所述的一种考虑微气候反馈的建筑-电网需求响应碳减排潜力评估方法，其特征在于：
所述基线功率、最大等效充电功率、最大等效放电功率和等效储能容量分别满足如下关系：
P_b^base = COP_b^-1·[(T_a - T_b^comf)·K_b·A_b^s + C_a·ρ_a·V_b·(T_a - T_b^comf)·N_b^ex + ε_b·A_b + I_b^solar·A_b^sol]
P_b^char = COP_b^-1·[(T_b^comf - T_b^min)·K_b·A_b^s + C_a·ρ_a·V_b·(T_b^comf - T_b^min)·N_b^ex]
P_b^disc = COP_b^-1·[(T_b^max - T_b^comf)·K_b·A_b^s + C_a·ρ_a·V_b·(T_b^max - T_b^comf)·N_b^ex]
E_b^eq = COP_b^-1·C_a·ρ_a·V_b·(T_b^max - T_b^min)
其中，COP_b为空调性能系数，T_b^comf为最舒适温度，T_b^min和T_b^max分别为舒适温度下限和上限。
5、根据权利要求1所述的一种考虑微气候反馈的建筑-电网需求响应碳减排潜力评估方法，其特征在于：
所述步骤S3中，首先依据待评估建筑与多个天气站之间的距离对天气站温度进行加权，得到建筑所在网格的气象基准温度；
再依据网格内建筑密度、城市形态或开敞程度估计城市热岛温升；
同时根据建筑空调排热功率估计空调排热诱导温升；
最终将气象基准温度、城市热岛温升和空调排热诱导温升叠加，得到网格局地温度。
6、根据权利要求5所述的一种考虑微气候反馈的建筑-电网需求响应碳减排潜力评估方法，其特征在于：
所述天气站加权温度、建筑密度、空调排热功率和局地温度分别满足如下关系：
w_is = d_is^-2 / Σ(d_is′^-2)
T_i(t) = Σ(w_is·T_s(t))，T̄_i = (1/N_t)·ΣT_i(t)
D_z = n_z / A_z × 10^6
Q_i^rej = P_i^disc·(1 + 1/COP_i)
ΔT_z^AC = k_z·[Σ(Q_i^rej)] / A_z，i∈z
T_z^local = T_z^met + ΔT_z^UHI + ΔT_z^AC
其中，d_is为建筑i与天气站s之间的距离，D_z为网格z的建筑密度，n_z为网格z内建筑数量，A_z为网格面积，Q_i^rej为建筑i的空调排热功率，k_z为网格热扩散系数，T_z^local为网格局地温度。
7、根据权利要求1所述的一种考虑微气候反馈的建筑-电网需求响应碳减排潜力评估方法，其特征在于：
所述步骤S3中，空调性能系数COP依据建筑用途类型和局地温度进行修正，修正后用于更新单建筑的基线功率、等效充放电功率和等效储能容量。
COP_i = min(COP_max，max[COP_min，COP_base(u_i) - k_cop·(T̄_i - T_ref)])
8、根据权利要求1所述的一种考虑微气候反馈的建筑-电网需求响应碳减排潜力评估方法，其特征在于：
所述步骤S4和步骤S5中，建筑群聚合等效储能容量和聚合等效放电功率分别为：
E_agg = ΣE_i^eq
P_agg = ΣP_i^disc
将所述聚合等效放电功率作为系统备用资源或可调负荷资源嵌入电力系统调度模型；
碳减排潜力通过接入需求响应前后发电机出力变化与对应机组排放因子的乘积求和获得。
9、根据权利要求8所述的一种考虑微气候反馈的建筑-电网需求响应碳减排潜力评估方法，其特征在于：
所述碳减排潜力满足如下关系：
ΔC_mit = Σ[(P_g^gen - P_g^gen,DR)·γ_g]
其中，P_g^gen和P_g^gen,DR分别为未接入和接入需求响应时机组g的出力，γ_g为机组g的碳排放因子。

说  明  书
一种考虑微气候反馈的建筑-电网需求响应碳减排潜力评估方法
技术领域
本发明涉及城市综合能源系统灵活性评估与建筑-电网协同低碳运行领域，尤其涉及一种将建筑温控负荷等效储能、城市微气候修正和电力系统边际排放评估相结合的建筑群需求响应碳减排潜力评估方法。
背景技术
在大型能源输入型城市中，建筑运行所消耗的电力通常主要来源于城市边界外部的上游电源，因此城市运行碳排放并不完全由本地终端能效决定，而与外部发电结构和调度状态密切相关。传统建筑节能评估方法更关注建筑本体节能和直接排放，难以准确量化建筑侧柔性负荷通过影响电力系统调度所带来的间接碳减排价值。
现有建筑需求响应研究通常将空调等温控负荷视为可调资源，并利用建筑热惯性进行短时移峰、削峰或辅助服务。然而，多数方法仅在单建筑或均质建筑群尺度开展分析，未充分考虑城市空间异质性、城市热岛效应、空调排热再反馈以及局地温度差异对空调性能系数和需求响应能力的影响。
另一方面，电力系统低碳调度研究通常从系统层面分析可再生能源消纳、机组组合和边际排放，但往往缺少对建筑群柔性形成机理的细粒度刻画，尤其缺乏从建筑几何、微气候和空调排热反馈出发，对城市建筑群需求响应碳减排潜力进行空间化、定量化评估的技术路线。
因此，亟需一种能够同时表征单建筑热惯性、城市局地微气候修正和系统级碳排放变化的评估方法，以提高城市建筑群需求响应碳减排潜力分析的准确性和可解释性。
发明内容
一、要解决的技术问题
本发明旨在解决现有技术中存在的以下问题：一是建筑需求响应能力评估中忽略城市空间异质性和微气候反馈，导致柔性容量估计偏差；二是建筑侧灵活性与电力系统碳排放之间缺少统一耦合评估框架，难以获得建筑群需求响应的真实碳减排潜力；三是现有方法缺少可输出空间分布结果的量化流程，难以支撑城市尺度的需求响应规划与低碳治理。
二、技术方案
为实现上述目的，本发明提供一种考虑微气候反馈的建筑-电网需求响应碳减排潜力评估方法，包括以下步骤：
步骤1，采集城市建筑群基础数据。所述基础数据包括建筑轮廓、建筑高度、建筑用途、建筑所在坐标、舒适温度上下限、天气站观测数据以及电力系统机组排放因子；并将待评估区域离散为多个空间网格，以建立建筑到网格的映射关系。
步骤2，建立单建筑温控负荷等效储能模型。基于建筑室内热平衡关系，分别求取在最舒适温度、舒适温度下限和舒适温度上限对应的空调功率，进而定义温控负荷的基线功率、等效充电功率、等效放电功率和等效储能容量。
C_a·ρ_a·V_b·dT_b^r/dt = (T_a - T_b^r)·K_b·A_b^s + C_a·ρ_a·V_b·(T_a - T_b^r)·N_b^ex + ε_b·A_b + I_b^solar·A_b^sol - Q_b^cool
在短时需求响应分析中，将建筑视为单热容热区，并认为在基线状态下室内温度维持于最舒适温度。由此得到空调基线功率及等效储能模型如下：
P_b^base = COP_b^-1·[(T_a - T_b^comf)·K_b·A_b^s + C_a·ρ_a·V_b·(T_a - T_b^comf)·N_b^ex + ε_b·A_b + I_b^solar·A_b^sol]
P_b^char = COP_b^-1·[(T_b^comf - T_b^min)·K_b·A_b^s + C_a·ρ_a·V_b·(T_b^comf - T_b^min)·N_b^ex]
P_b^disc = COP_b^-1·[(T_b^max - T_b^comf)·K_b·A_b^s + C_a·ρ_a·V_b·(T_b^max - T_b^comf)·N_b^ex]
E_b^eq = COP_b^-1·C_a·ρ_a·V_b·(T_b^max - T_b^min)
步骤3，建立城市微气候修正模型。首先采用反距离平方加权方法对多个天气站的气温进行融合，得到建筑所处网格的气象基准温度；然后根据网格建筑密度确定城市热岛温升；再由建筑等效放电功率推算空调排热功率，并结合网格热扩散系数计算空调排热引起的局地温升；最终叠加获得网格局地温度。
w_is = d_is^-2 / Σ(d_is′^-2)
T_i(t) = Σ(w_is·T_s(t))，T̄_i = (1/N_t)·ΣT_i(t)
D_z = n_z / A_z × 10^6
Q_i^rej = P_i^disc·(1 + 1/COP_i)
ΔT_z^AC = k_z·[Σ(Q_i^rej)] / A_z，i∈z
T_z^local = T_z^met + ΔT_z^UHI + ΔT_z^AC
局地温度将反馈修正空调性能系数COP，所述COP按建筑用途类型和局地温度变化进行截断线性修正：
COP_i = min(COP_max，max[COP_min，COP_base(u_i) - k_cop·(T̄_i - T_ref)])
步骤4，进行建筑群需求响应聚合。将所有建筑的等效储能容量与等效放电功率相加，得到城市建筑群的聚合柔性包络：
E_agg = ΣE_i^eq
P_agg = ΣP_i^disc
步骤5，开展系统级碳减排评估。将聚合需求响应资源作为备用资源、可调负荷资源或虚拟储能资源嵌入电力系统机组组合模型或经济调度模型，对比接入需求响应前后的机组出力差异，并结合机组排放因子，计算需求响应所对应的碳减排潜力：
ΔC_mit = Σ[(P_g^gen - P_g^gen,DR)·γ_g]
进一步，可将各建筑或各网格的碳减排贡献映射到地理空间中，形成建筑群需求响应碳减排潜力分布图。
三、有益效果
与现有技术相比，本发明至少具有如下有益效果：
1）提出了面向建筑需求响应的等效储能建模方法，能够在不直接求解高维空调群体控制问题的情况下，提取单建筑温控负荷的可调容量和可调功率边界；
2）将天气站观测、建筑密度、城市热岛效应和空调排热反馈统一纳入微气候修正模型，能够更准确地描述城市建筑群需求响应能力在空间上的异质性；
3）构建了建筑群需求响应与电力系统低碳调度的耦合评估链路，可直接量化建筑侧柔性对上游发电碳排放的影响；
4）可输出建筑级、网格级和城区级的碳减排潜力空间分布结果，适用于城市需求响应规划、建筑群灵活性评价和城市低碳治理场景。

具体实施方式
下面结合实施例对本发明作进一步说明，但本发明的保护范围不限于以下实施例。
实施例一：数据准备与空间离散。选取澳门城市区域作为示例研究对象，收集2023年夏季逐时气象数据，数据来源包括9个天气站的气温、湿度、太阳辐射和风速观测；建筑轮廓信息来自OpenStreetMap，高度信息对缺失项采用KNN方法补全，并辅以商业建筑数据进行校核；将城市区域离散为若干网格单元，建立建筑-网格映射关系；电力系统层面采用IEEE 24节点系统作为示范调度系统，并配置发电机排放因子。
实施例二：单建筑需求响应能力求取。针对商业建筑、公共建筑、住宅建筑和工业建筑等不同类型建筑，根据建筑体积、围护结构参数和舒适温度区间建立单建筑等效储能模型。对处于最舒适温度、舒适温度下限和舒适温度上限三种状态下的空调功率分别进行计算，获得相应建筑的基线功率、最大等效充电功率和最大等效放电功率，并求得等效储能容量。
实施例三：城市微气候修正。对每一建筑，通过其与9个天气站之间的距离确定加权温度；以网格为单位统计建筑密度，并根据密度分位点构建城市热岛温升；利用建筑等效放电功率推导空调排热功率，再依据网格面积和热扩散系数计算空调排热诱导温升；将三部分温度叠加得到网格局地温度，并据此修正空调COP。实施中发现，澳门半岛中部高密度区域局地温升约为1.6℃，对应COP下降约4.2%，而氹仔和路环区域局地温升较小。
实施例四：建筑群聚合及碳减排评估。将所有建筑的等效放电功率在时间维度上进行聚合，形成城市建筑群需求响应包络，并将其作为系统备用资源接入机组组合或经济调度模型。对比有无需求响应参与时的机组出力差异，得到碳减排结果。在澳门示例中，建筑群最大聚合等效放电功率约为68MW；考虑微气候反馈后，建筑群总需求响应潜力增加约73MWh；按全年尺度估算，需求响应带来的碳减排量约为83.9吨CO2/年，约占澳门制冷相关碳排放的24%。
实施例五：结果输出。基于建筑或网格的贡献值生成碳减排潜力空间分布图，结果表明，大体量商业建筑和公共建筑对碳减排贡献更显著，而高密度住宅区虽然单体贡献较小，但由于数量众多，汇总后仍具有明显减排价值。
以上实施例说明，本发明能够实现从建筑热惯性到城市空间异质性再到系统边际排放的全链路量化评估，从而为城市建筑群需求响应资源开发和低碳调度提供技术支撑。
